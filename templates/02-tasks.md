## 任務清單

狀態欄用 `todo` / `wip` / `done` / `blocked`，**每做完一個任務就立刻更新該列**。

- `wip` — 開始動這個任務就先標上，並在 `notes.md`「進行中」寫一行
  「做到哪、下一步是什麼」。這是為了讓中斷點的粒度細到任務**內部**：
  只靠 `todo`／`done` 的話，寫到一半被中斷、又還沒 `git add`，那段進度就沒有落點。
- `blocked` — 要在 `notes.md`「卡住」節說明卡在哪。
- **關聯 Gotcha** — 若這個任務的「檔案」欄命中該 repo state 的 `refs/codebase-gotchas.md` 記錄位置，
  這裡填對應編號（例如 `G4`），代表動手前已經重新讀過那條記錄、確認現況是否還成立。
  `coverage-lint.js` 會自動比對兩邊路徑，命中但這欄空白時會印出警告。

| # | 任務 | 服務 AC | 檔案 | 前置 | Done 條件 | 狀態 | 關聯 Gotcha |
| --- | --- | --- | --- | --- | --- | --- | --- |
| T1 | | → R1.1 | | — | | todo | |
| T2 | | → R1.2 | | T1 | | todo | |
