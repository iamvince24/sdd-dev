把這個項目專用的參考文件丟在這一層：spec、API doc、Postman export、
DB schema、UI 截圖、Figma 匯出、對話截圖皆可。

支援的格式：`.md` `.txt` `.json` `.yaml` `.csv` `.sql` `.html` `.pdf`
`.png` `.jpg`（圖片與 PDF 我都讀得到）。

檔名建議加前綴分類，例如：
- `spec-<主題>.md`
- `api-<endpoint 群組>.md` 或 `.json`
- `ui-<畫面>.png`

記得在 `../00-spec.md` 第 7 節「參考文件」表格列出來並註明要看的重點。
